# Bundled open recordings

This directory contains the two original OGG recordings downloaded from Wikimedia Commons.

- `FurElise_V_Gao_CC0.ogg`: V. Gao (Gaodifan), *Für Elise*, CC0 1.0.
- `FurElise_JMC_Han_CC_BY-SA_4.0.ogg`: Jason M. C. Han, *For Elise (Für Elise) Beethoven JMC Han*, CC BY-SA 4.0.

See `../AUDIO_CREDITS.md` for original file links, credits and license URLs. Originals are embedded without editing.
